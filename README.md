# Floating-Point Unit in VHDL

A floating-point arithmetic unit implemented in VHDL as part of the CEG3556 Computer Architecture course at the University of Ottawa.

This project includes two major components:

- A floating-point adder
- A floating-point multiplier

Both designs were developed using modular VHDL components and Intel / Altera Quartus II.

## Project Structure

vhdl-floating-point-unit/
├── Adder/
└── Multiplier/
## Floating-Point Adder

The adder design includes components for:

- Exponent comparison
- Mantissa alignment
- Addition and subtraction
- Right shifting
- Normalization
- Register-based datapath control
- Control path and datapath separation

## Floating-Point Multiplier

The multiplier design includes components for:

- Mantissa multiplication
- Exponent arithmetic
- Sign handling
- Addition and complementation
- Register and counter logic
- Control-path implementation
