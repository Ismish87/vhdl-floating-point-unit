# Floating-Point Unit in VHDL

A floating-point arithmetic unit implemented in VHDL as part of the CEG3556 Computer Architecture course at the University of Ottawa.

This project includes two major components:

- A floating-point adder
- A floating-point multiplier

Both designs were developed using modular VHDL components and Intel / Altera Quartus II.
